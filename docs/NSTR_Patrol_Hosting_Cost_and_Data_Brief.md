## 2. Option 2 — If You Want Your Own In-House Server

If you prefer to keep all data in your own office, you can use your own server instead of the cloud. For that, you will need to arrange a server with the capacity below.

**One-time server purchase and electricity/maintenance will be separate.**

### What Specifications Does the In-House Server Need?

To handle the data we collect (details in Section 3), the in-house server should have:

| Requirement | What is Needed |
| :--- | :--- |
| **Storage Space** | **50 GB minimum, 100 GB recommended** for 6 months of data |
| **Memory (RAM)** | **8 GB minimum** |
| **Processor** | **4 Core** |
| **Support for Staff** | Can handle **100 staff** using the system at the same time |
| **Data Safety** | Daily automatic backup (space included in 100 GB) |
| **Internet** | Stable connection for phones to sync data |

This setup will comfortably handle the daily data load and keep 6 months of records ready for reports and maps.

---

## 3. How Much Data Do We Collect?

This is how much patrol information is collected automatically when staff are on duty.

*   **Staff Count:** 100 forest staff
*   **Duty Time:** Average 8 hours per day
*   **Recording Speed:** Phone saves location every **3 seconds**

| Period | Total Records Collected |
| :--- | :--- |
| **Per Person / Per Day** | **~ 9,600 records** |
| **All 100 Staff / Per Month** | **~ 2,88,000 records** |
| **All 100 Staff / 6 Months** | **~ 17,28,000 records** |

*Each record is very small — about 4KB.*

**How long do we keep it?**
We keep **6 months** of data. After 6 months, older data is automatically cleared and space is reused. So the 50–100 GB is on a 6-month rolling cycle.

**Simple Growth Example:**
*   50 staff → about half the space and cost
*   200 staff → about double the space and cost
*   Growth is direct and predictable
